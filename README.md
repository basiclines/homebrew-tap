# Homebrew Tap for basiclines

This repository contains Homebrew formulae for tools by [basiclines](https://github.com/basiclines).

## Installation

```bash
brew tap basiclines/tap
```

## Available Formulae

### rampa

Generate mathematically accurate color palettes from a base color.

```bash
brew install rampa
```

**Usage:**
```bash
rampa --base="#3b82f6"
rampa -b "#3b82f6" --output=css --name=primary
```

See [rampa-studio](https://github.com/basiclines/rampa-studio) for full documentation.
